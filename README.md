# daybook · 工作流水帳

> 版本：**1.65.0**（視窗標題也會顯示）

取代用記事本寫的每日工作紀錄（一個 `.txt` 一天一天往下記）的桌面程式：照原本的寫法一天一天記，
工具負責把同一支程式、同一個主題的紀錄串起來——「記」跟記事本一樣快，「找」比記事本快。

紀錄是一般的文字檔（一天一個 `.md`），放在自己選的資料夾；外面用別的編輯器改了（存成帶 BOM 的 UTF-8 也認得），畫面也會跟著變。

## 功能一覽

- **日記本**：一天分「已處理」「待處理」兩塊，用卡片新增；搜尋、程式代號／事件的時間軸、日期清單與日曆、
  回顧（一次看一段時間的已處理）、標記（還要注意、還沒完的事，可以分類）
- **剪貼簿**：常用的文字點一下就複製，可以帶當下的日期時間
- **記事本**：純文字。左邊記事清單可以開資料夾、找名稱、右鍵選單、照名稱／修改時間／建立日期排，上面頁籤放開著的；
  有行號、找字取代、Ctrl+D 多游標、整行操作，存檔照 VS Code
- **文件檢視**：唯讀看釘住的資料夾裡的 `.md`、`.html`，例如 AI 產出的報告、規格
- **截圖**：取代剪取工具。框選、畫框和箭頭，存成編號、同時複製；留下來的取名另放，拖框選好幾張一起複製、右鍵列印，清掉 N 天前的
- **常用**：常開的程式、資料夾、網址放在左欄，點一下就開
- **匯入、匯出、備份**：匯出日期區間或全部（Markdown、Excel，或擴充的格式）；整個紀錄資料夾壓成一個 zip
- **自訂**：格式擴充（匯入、匯出別的格式，可以請 AI 寫）、外觀包（背景圖、空白時的插圖）、字型、黑暗模式、
  介面語言（內建繁體中文，其他語言請 AI 翻、貼回來裝）
- **好按**：打字時的提示清單、換日快捷鍵；最下面的狀態列寫游標所在地方能按的鍵，F1 看全部快捷鍵

還沒做的見〈之後〉。

## 下載與安裝

只有 Windows 版。到 GitHub 的 [Releases](https://github.com/a0983610/deybook/releases) 下載打包好的程式，或自己從原始碼跑（見下面）。
打包有兩種：

| 檔案 | 說明 |
|---|---|
| `daybook-版本號-portable.exe` | 可攜版：點兩下就跑，每次開要先解壓（約 7～10 秒） |
| `daybook-版本號-setup.exe` | 安裝檔：裝一次（只裝給自己、不用管理員），有捷徑、開得快 |

**第一次開**：畫面中間會請你按「選擇資料夾…」，選紀錄要放在哪個資料夾（不會一開就跳視窗）；原本的資料夾不見了也一樣。
選好的位置存在 `%APPDATA%\daybook\settings.json`，之後要換按左下角「變更資料夾…」。
設定檔讀不懂（例如手改壞了）時，會改名成 `settings.json.bad-日期時間` 留著、提示一次，這次當作沒設定（要重新選資料夾）。

只能開一個視窗：已經開著的話，再開一次會把開著的叫到前面。

### 從原始碼跑

```
npm install      裝 Electron 45.0.0、marked 18.1.1（文件檢視轉 md 用）；Electron 執行檔第一次啟動時才下載
npm start        啟動
daybook.cmd      點兩下就開，跟 npm start 一樣；黑色視窗開完就關掉
```

打包、測試和其他指令見 [`開發.md`](開發.md)。

## 紀錄怎麼寫

### 資料夾裡有什麼

```
<紀錄資料夾>/                          ← 自己選的資料夾（見〈下載與安裝〉）
├── 待辦.md                           ← 待處理：還沒處理完的事，不分哪一天
├── 標記分類.json                      ← 標記的分類清單（自己加的），第一次加分類才建
├── 剪貼簿.md                          ← 剪貼簿的文字：標題沒縮排、要複製的內文 Tab 縮排，第一次新增才建
├── 記事本/週會.txt                     ← 記事本：一份一個 .txt，檔名就是名稱（UTF-8、\n 換行），第一次存檔才建；
│   └── 工作/2026/規劃.txt                裡面可以開資料夾，幾層都可以
├── journal/2026/10/2026-10-05.md    ← 已處理：一天一檔，檔名就是日期
└── topics/多統編發票.md               ← 跨好幾支程式的主題頁（還沒做，見〈之後〉）
```

### 一天裡面怎麼寫

跟舊 txt 一樣：

```
CWIN301000 撥入單 BUG
	Q1.備料單產生的單據，走自動核准按修改、刪除時請直接擋住
	Q2.查詢\來源單別，請將「請選擇」改為「全部」 (撥出單一起調)
雅琦問題：發票號碼XA34259000已於1/21作廢，但1/22又產生一次作廢的XML [待回覆]
	->雅琪問台應看看
```

| 寫法 | 意思 |
|---|---|
| 沒縮排的行 | **條目標題** |
| Tab（或空白）縮排的行 | 條目內容 |
| `->` 開頭 | 處理結果／原因，畫面上特別標示 |
| 標題行**最後面**的 `[待回覆]` | 狀態，現在只在待處理用（沒標就是待處理）。只認標題行尾；舊的 `[待處理]` `[完成]` 也認得 |
| 標題裡的 `^數字`（放在狀態前面） | 事件編號：已處理的事隔天又有後續時，今天另記一筆、用同一個編號串起來；按「+ 更新」時自動編 |
| 待處理裡的 `->MM/DD …` | 待處理那一筆的進展，按「+ 更新」時自動帶日期 |
| 標題行尾的 `[隱藏]` | 待處理先收起來不看，可以跟 `[待回覆]` 同時有：`週報 [隱藏] [待回覆]` |
| 標題行尾的 `[標記]` | 已處理的事還要注意、還沒完；跟其他行尾標記一起時寫成 `^編號 [隱藏] [標記] [狀態]` |
| 標題行尾的 `[標記:分類]` | 標記帶分類，例 `[標記:等客戶]`；冒號全形也認，寫回去是半形。只寫 `[標記]` 是未分類 |
| 標題裡的 `#主題名` | 把這筆歸進 `topics/主題名.md`（主題頁還沒做） |
| 連續幾行只有「代號＋程式名稱」的標題，底下才接內容 | 這幾支程式共用那段內容（細的規則見 [開發筆記 D009](開發筆記/匯入舊檔.md)） |

在畫面上加、改、刪卡片（含 + 更新、處理完）時，只有標題的那筆不會因此跟旁邊的標題變成共用內容：需要時中間會多空一行（空行隔開的標題不算連續）。

### 工具自動抓的東西

不用另外標，從標題行抓：

| 抓什麼 | 例 | 用途 |
|---|---|---|
| 程式代號 | `CWMM3030`、`eWCH3050`、`TX_GetInvoiceNumber`（標題裡任何位置都算） | 同代號的條目自動串成時間軸 |
| 類型 | `BUG`、`BB`、`規格調整`、`新程式` | 篩選 |
| 人名 | `秀屏問題`、`看雅琦問題` → 秀屏、雅琦 | 篩「誰來問的」 |
| 工單號 | `Wc3620251231005` | 篩選 |

### 主題頁（還沒做）

```markdown
---
title: 支援開立多統編發票
status: 完成
---
摘要、規格重點、相關單號……
```

## 功能說明

### 畫面配置

- **最左邊的頁籤列**（像 VS Code 的活動列）：「日記本」（左欄是搜尋、日期）、「剪貼簿」（左欄換成剪貼簿）、「記事本」（中間換成記事本、左欄換成記事清單）、
  「文件檢視」（中間換成 .md、.html、左欄換成釘住的資料夾）、「截圖」（中間換成截圖頁，沒有自己的左欄）、「常用」（左欄換成常用的程式、資料夾、網址，中間不換）；
  點正在看的那個收起左欄、中間變寬，點另一個打開並換成它；收起來、放哪一個都記在這台電腦。
  收起來、或放剪貼簿時按 Ctrl+F 會先打開日記本（記事本開著時 Ctrl+F 是找記事本裡的字；文件檢視開著時不理）。
- 頁籤列最底下是**齒輪「設定」**（像 VS Code 左下角的齒輪）：點了彈出小選單，分類列：
  「資料」匯入…、匯出…、備份…；「自訂」格式…、外觀…、語言…（見〈設定〉）。點一個打開那頁（匯入、備份直接做）；Esc、點外面收起來
- **分隔線可以拉**（像 VS Code）：左欄｜中間、已處理｜待處理、待處理｜輸入區（文字模式是兩塊中間那條），拉多大就多大、記在這台電腦；
  點兩下線還原，全部一起還原用「外觀」頁最上面的「還原預設大小」
- **捲軸**（像 VS Code）：沒有箭頭、平常藏起來，滑鼠移進那塊才出現；中間那欄 14px、其他 10px
- **黑暗模式**：右上角「黑暗模式／淺色模式」一鍵切換，記在這台電腦；沒切過就跟 Windows 設定。
  顏色照 VS Code Dark+，視窗標題列、視窗底色也跟著變暗（最小化時不會閃白）。
  標題列是自己畫的：35px 跟 VS Code 一樣高、不跟著畫面縮放；原生選單列沒有了（原本按 Alt 才出現）
- **快捷鍵說明**：最下面的狀態列寫游標所在地方能按的鍵；按 **F1**（或點狀態列右邊）看全部快捷鍵
- **畫面縮放**：**Ctrl+=** 放大、**Ctrl+-** 縮小、**Ctrl+0** 還原，**Ctrl＋滾輪**也可以；整個畫面一起縮放、記住大小，
  狀態列右邊顯示比例（點一下還原）
- **記住視窗**：關掉時記下視窗大小、位置、有沒有放到最大（設定檔的 `window`），下次照著開；
  記的位置現在看不到（那個螢幕拔掉了）就照預設開

### 日記本

#### 已處理／待處理

中間上面是這一天已處理的事，下面是待處理（不分哪一天，一直都在）。
兩塊的高度跟著內容走、剩下的給輸入區；點標題列可以縮起來。
已處理多一筆（＋ 已處理、處理完 ↑、已處理+未完標籤）就捲到新的那一筆的頂端。

**刪除不跳詢問；按錯了按 Ctrl+Z 復原上一個卡片動作**（游標不在輸入框時）。

#### 卡片輸入

一打開停在今天。最底下的表單填標題（Enter 換到內文）、內文，
按 **＋ 待處理**（Ctrl+Enter）或 **＋ 已處理（這一天）**（Ctrl+Shift+Enter）。

**提示清單**（像 VS Code）：打字時框下面列出以前寫過的——標題是整行標題和「代號＋程式名稱」，
內文是游標那一行的內文（這個標題底下寫過的排前面）；開頭或中間對得上都算，用過越多次越前面。
**↑↓** 選、選中的用灰字預覽，**Tab** 帶入；按過 ↑↓ 之後 **Enter** 也是帶入（沒按過照舊換到內文／換行）；**Esc** 關掉、**Ctrl+Space** 叫出來

#### 待處理的卡片

**待回覆**（點一下切換）、**+ 更新**（接在底下、帶今天日期）、**處理完 ↑**（整筆搬到上面正在看的那一天）、
**已處理+未完標籤**（跟處理完一樣搬上去，再標上「未完」標記）、**隱藏**（收到最底下「已隱藏 N 筆」，點一下展開、可以取消隱藏）、編輯、刪除

#### 已處理的卡片

**標記**、**+ 更新**、編輯、刪除

- **標記**：還要注意、還沒完的事。點「標記」底下冒出一排分類鈕：「未分類」、自己加的分類、「＋ 新分類」，點一個就標上
  （按鈕亮起來、寫「標記·分類」，行尾加 `[標記:分類]`）；「＋ 新分類」打名稱按 Enter，加進分類清單並標上。標過的再點「標記」可以換分類或「取消標記」。
  分類清單存在資料夾的 `標記分類.json`（還沒用到的分類也留著）；改名、刪除分類現在要直接改這個檔。
  另有內建的分類「**未完**」，不在這個檔裡。
  左邊「清單｜日曆」旁邊的「**標記**」列出全部標記的（舊的在前），上面一排「全部｜未分類｜各分類」篩選鈕（後面寫筆數），點了只看那一類；
  每張可以直接「取消標記」；搜尋結果上也標「標記·分類」
- **+ 更新**：
  - 今天的：在同一筆底下加一行 `->…`
  - 過去的：在今天另記一筆，用 `^編號` 跟原本那筆串起來；原本那筆有標記的話，標記搬到今天這筆

#### 編輯卡片

按「編輯」改標題、內文，**Ctrl+Enter** 儲存。存不進去（標題空白、「數字＋.」開頭、在別的地方被改過）時提示，編輯框和打的字留著。
編輯中要換日、按別張卡片的動作、新增、Ctrl+Z、搜尋、看時間軸、換模式，會先問要不要放棄改的內容（游標先在「取消」）。

#### 文字模式

右上角切換，上下兩塊換成原文（那天的檔、`待辦.md`）。**唯讀**：可以捲動、選取、Ctrl+C 複製，打字打不進去；
要改切回卡片模式，卡片表達不了的寫法用外面的編輯器改（畫面會跟著變）。

#### 日期清單／日曆

左邊列日期，點了看那天；點過之後按 **↑ / ↓** 換到上一天／下一天；同一週一段底色，一週沒有、一週有。
**Alt+← / Alt+→** 跳到前一個／後一個有紀錄的日子，**Alt+Home** 回今天。
搜尋框底下切「清單」「日曆」：日曆一週從星期一開始、有紀錄的日子有點，‹ › 翻月；沒紀錄的日子也能點開來補記

#### 搜尋

左上搜尋框（Ctrl+F），空白隔開的每個詞都要出現，標題和內容都算。
打字時提示清單先列搜過的（搜越多次的越前面），再列內容裡的代號、程式名稱、人名；
按法跟新增表單一樣，按過 ↑↓ 的 Enter 是帶入再搜；有清單時 Esc 先關清單，再按一次才清掉

#### 時間軸

點卡片上的代號標籤，列出那支程式所有紀錄；點 `^編號` 標籤，列出那件事每一天的紀錄。舊的在前

#### 回顧

右上角最前面的「回顧」，中間列出一段時間的已處理（待處理不列），每天一段小標（`2026-10-26（一）· 2 筆`，點了打開那天）、底下是那天的卡片（唯讀）；舊的在前。
按了一律是這週（星期一到今天）；上面一列 **‹ ›** 換到起日那週的上一週／下一週，也可以自己填起訖。「← 回到那天」回去。
同一列的「**匯出這段…**」打開匯出列、起訖帶這段（之後回顧再換，匯出的不跟著換），選格式按「匯出這段」才匯出

### 剪貼簿

常用、要貼到別的地方的文字放這裡。點頁籤列的「剪貼簿」（剪貼簿圖示），左欄換成一張張卡片：標題＋內文（顯示三行）。

- **點卡片就把整段內文（不含標題）複製到剪貼簿**（用 Tab 選到按 Enter 也是）；換行是 Windows 的 `\r\n`。
- 「＋ 新增」：標題（Enter 換到內文）、內文（Tab 縮排），Ctrl+Enter 或「儲存」，兩個都要填；新的放最後面（表單開在清單最下面）。
  內文原封不動：頭尾的空白、空行、最後的換行都照存、照複製（整段都是空白才不給存）。
- 滑過卡片右上角有「編輯」「刪除」；刪除不跳詢問，Ctrl+Z 復原。
- **調順序**：卡片用滑鼠拖到別的位置（放開的地方畫一條線），或用 Tab 選到卡片按 Alt+↑／Alt+↓ 搬一格；順序就是 `剪貼簿.md` 裡的先後，Ctrl+Z 復原。有一張在編輯時不能搬。
- 存在資料夾的 `剪貼簿.md`（寫法照紀錄：標題沒縮排、內文 Tab 縮排），外面用記事本改也會跟著變；搜尋、匯出不含剪貼簿。
- **日期符號**：內文寫 `[{yyyy.MM.dd HH:mm} cm8]`，複製出去是 `[2026.10.29 10:00 cm8]`（那一刻的日期時間）。符號照 C#、大小寫有分：
  `yyyy` 年、`yy` 年兩碼、`MM` 月、`M` 月不補零、`dd` 日、`d` 日不補零、`HH` 時（24 小時）、`H` 時不補零、`mm` 分、`ss` 秒；中文、標點照原樣（`{yyyy年M月d日}`）。
  大括號裡的英文字母整段都是這些符號才換，`{0}`、`{ get; set; }` 照原樣。卡片上符號那段換顏色；新增、編輯時內文底下預覽「複製時：…」。
  表單上的「**日期符號 ▸**」點了展開符號表和例子，點例子插進內文游標的位置

### 記事本

隨手記的純文字。點頁籤列的「記事本」（紙＋鉛筆圖示），中間換成記事本、左欄換成**記事清單**；
記事本開著時再點「記事本」收起／打開清單（跟日記裡點「日記本」一樣），點「日記本」回到日記。
**點剪貼簿不回日記**：左欄換成剪貼簿、中間還是記事本，一邊點卡片複製一邊貼進記事本；再點一次收起左欄，點「記事本」換回記事清單。
剪貼簿開著沒只記一份、跟日記共用。

#### 記事清單

像 VS Code 的檔案總管：`記事本\` 底下全部的記事，可以開資料夾（幾層都可以），照名稱排（數字照大小、不分大小寫）、資料夾在前面，點資料夾展開／收起。

- 點一下記事開成**預覽**的頁籤（斜體，再點別份就換掉它），點兩下、或在裡面打字就留下來。
- 上面四顆：新增記事、新增資料夾（加在選到的那個資料夾裡；選到記事就是它在的資料夾，點空白的地方是最上層）、排序、全部收合。
- **排序**：照名稱、修改時間、建立日期，時間的可以選新的在上面或舊的在上面；只排記事，資料夾一律在前面、照名稱。選的記在這台電腦（跟文件檢視各記各的）。
  存記事時建立日期不會變。
- 滑過一行出現 **✎ 改名**、**× 刪除**：記事不問，直接丟到資源回收筒（改過沒存的先寫進去）；資料夾裡有記事先問一次，整個丟到資源回收筒。
  **拖到資料夾**就搬過去（拖到空白的地方是最上層；那裡已經有同名的不搬）。
- **找記事**：清單上面那格，打字就只留名稱符合的記事（不分大小寫、空白隔開的每個詞都要有，資料夾跟著打開）；Enter 開第一份、Esc 清掉。記事本開著時 **Ctrl+P** 游標跳進去。
- 點過清單上那一行之後，**F2** 改名、**Delete** 刪除（先問，Enter 確定）。
- **右鍵**：新增記事、新增資料夾（加在那個資料夾裡）、改名、刪除、在檔案總管中顯示、複製路徑；空白的地方只有新增（最上層）。
- 開著的頁籤、改過沒存的跟著改名、搬走；開著哪幾份、展開了哪些資料夾記在這台電腦。

#### 編輯

- 左邊有**行號**：長的行自動換行，行號照真的換行算，折下來的不標號。
- **Ctrl+F 找字**：右上角跳出小框，只找正在看的那份、不分大小寫；找到的全部標顏色、目前那個深一點、寫「2 / 5」；
  Enter 下一個、Shift+Enter 上一個（到底繞回來），Esc 關掉、游標回到找到的那個；選著一段字按 Ctrl+F 就拿來找。
- **Ctrl+H 取代**：找字的框多一列（左邊 ▸ 也能開關），取代的框按 Enter 換掉目前那個、跳到下一個，Ctrl+Alt+Enter（或「全部取代」）一次換掉全部；在文字框按 Ctrl+Z 一次復原。
- **Ctrl+G 跳到第幾行**：上面中間跳出小框，打行號按 Enter（比最後一行大就到最後一行），Esc 取消。
- **Ctrl+D 多游標**（照 VS Code）：沒選字時選游標所在的詞（中文也切得出詞），再按一次多選下一個一樣的（大小寫要一樣；從詞開始的不找黏在英數字中間的）；
  好幾個選取時打字、輸入法、Backspace、Delete、Enter、Tab、貼上、複製、剪下、方向鍵、Home、End 都每個一起，Esc 或點一下回到一個。
- **整行、縮排**（照 VS Code）：Alt+↑↓ 這一行（選好幾行就那幾行）往上／下搬、Shift+Alt+↑↓ 複製一份、Ctrl+Shift+K 刪掉；沒選字時 Ctrl+C／Ctrl+X 是整行，貼的時候插在游標那一行上面；
  選好幾行按 Tab／Shift+Tab 每一行縮排／退縮排（空行不加；Shift+Tab 拿掉一個 Tab 或最多 4 個空白），Enter 換行時帶上一行的縮排。

#### 頁籤與存檔

- 上面一排頁籤只放**開著的**，最右邊「**＋**」新增（叫「新記事 1」「新記事 2」…，接在最後面，存在清單上選到的資料夾）；點頁籤換一份。直接打字（Tab 縮排）。
  開著兩份同名的（在不同資料夾）時，頁籤後面淡淡寫在哪個資料夾。
- **存檔照 VS Code**：**Ctrl+S** 才存，改過沒存的頁籤上一個 ●、右上角寫「未存檔」。新記事先不建檔，Ctrl+S 時頁籤變成取名的框（預設是第一個有字的行），Enter 才存成檔。
  沒存的（新記事、改過沒存的）停手 0.6 秒暫存到這台電腦的 `%APPDATA%\daybook\note-backup\`，關掉 daybook 再開還在。
- **點兩下頁籤改名**（新記事是取名存檔、預覽的是留下來；Enter 改好、Esc 取消；Windows 檔名不能用的字、同一個資料夾裡同名會提示）。
- 頁籤上的 **×** 是**關掉**（檔案還在）：改過沒存的、有字的新記事先問「存／不存／取消」，其他直接關。刪除在記事清單上。
- **頁籤按右鍵**（照 VS Code）：關閉、關閉其他、關閉右側、全部關閉、在檔案總管中顯示、複製路徑（還沒存的新記事沒有後兩項）；按右鍵不會換成看那一份。
  一次關好幾個時改過沒存的**一次問**：好幾份是「全部存／全部不存／取消」，全部存時新記事沒有名字，先留著不關（要自己取名）。
- 存在資料夾的 `記事本\…\名稱.txt`，外面用 Windows 記事本改、外面建資料夾也會跟著變（改過沒存的留著畫面上的）；備份會一起壓（沒存的不算），搜尋、匯出不含記事本。
- 讀得懂 UTF-8（有沒有 BOM 都可以）和 UTF-16 LE；不是的（Big5、ANSI 存的）打不開，會提示先用記事本另存成 UTF-8——照 UTF-8 硬讀會變亂碼，一存原檔就毀了。

### 文件檢視

**唯讀**看 AI 產出的報告、筆記、規格（`.md`、`.html`、`.htm`），不管放在哪個資料夾。
點頁籤列的「文件檢視」（M↓ 圖示），中間換成那份文件、左欄換成清單；
開著時再點收起／打開清單，點剪貼簿、記事本、日記本跟記事本一樣（剪貼簿開著沒共用一份）。

- **清單**：上面「**＋**」（資料夾＋）**釘一個資料夾**（跳選資料夾的視窗）；可以釘好幾個，照釘的順序排在最上面一層，滑過出現 **×** 不釘（檔案不會動）。
  底下只列有 .md、.html 的資料夾和那些檔（幾層都進去，`node_modules`、`.git` 裡的不列），照名稱排、資料夾在前面；.md 的名稱不寫 .md，.html 寫出副檔名。
  上面的**排序**鈕跟記事清單一樣：檔案可以改照修改時間、建立日期排（新的在上面／舊的在上面），資料夾照名稱；外面改了檔就照新的時間排。
- **頁籤**：點一下開成預覽的頁籤（斜體，點下一份就換掉），點兩下留下來；頁籤上 × 關掉。開著兩份同名的（例如每個專案的 README），頁籤後面淡淡寫在哪個資料夾。
  頁籤按右鍵：關閉、關閉其他、關閉右側、全部關閉、在檔案總管中顯示、複製路徑。
- **清單按右鍵**：.md、.html、資料夾有在檔案總管中顯示、複製路徑、複製相對路徑（從釘住的資料夾算起，`/` 隔開，例：`子/說明.md`）；
  釘住的資料夾有在檔案總管中顯示、複製路徑、不釘這個資料夾；空白的地方是「釘資料夾…」。唯讀，沒有改名、刪除。.html 的頁籤、清單右鍵多「**用瀏覽器開**」（用 Windows 預設的程式開那個檔）。
- **.md** 照 GitHub 的 Markdown 排：標題、清單、核取清單（不能勾）、表格、程式碼、引言、刪除線；字的大小照「外觀」頁的內容字；
  檔案裡的 HTML 照原字顯示、不會執行，只有 `<br>` 換行、`<!-- 註解 -->` 不顯示；圖片不顯示，換成「〔圖：說明〕」。
- **.html** 照檔案自己的樣子排（自己的樣式、旁邊資料夾裡的圖照樣出來，Word 轉的 big5 也讀得對），白底；放在沙盒裡，碰不到 daybook 的資料。
  檔案裡的**程式不跑、不連網**（網路字型換本機的，複製鈕、全部展開這類要程式的鈕沒反應；小工具用「用瀏覽器開」）。
- **連結**：網址（http、https、mailto）用瀏覽器開（.html 裡 target=_blank 的也是）；相對路徑連到釘住的資料夾裡的 .md、.html 就在這裡開；.html 裡的 #段落照跳；其他的開不了。
- 檔案在外面改了**自動重畫**：.md 捲到哪留著；.html 重新載入、回到最上面。多了、少了清單跟著變（開著的被刪掉就關掉頁籤）；.md 換頁籤、回日記再回來，捲到哪都照舊（.html 回到最上面）。
- 釘了哪些資料夾記在設定檔（`%APPDATA%\daybook\settings.json` 的 `mdRoots`）；開著哪些、展開了哪些記在這台電腦。找字（Ctrl+F）還沒做

### 截圖

取代 Windows 剪取工具。點頁籤列的「截圖」（裁切的直角圖示），中間換成截圖頁（沒有自己的左欄；開著剪貼簿時照樣放剪貼簿）。

- **「＋ 截圖」**：daybook 先變透明，每個螢幕蓋一層停住的畫面，拉框選範圍；框旁邊出現工具列：**框**、**箭頭**、**直線**（紅色；用哪個記在這台電腦，下次照上次的）、復原（Ctrl+Z）、取消（Esc）、**完成**（Enter）。
  框好之後在框裡拉是畫，框外拉是重新框；框上面寫存出去的大小。完成就存成**下一號** `639.png`、**同時複製到剪貼簿**，daybook 回來、提示存成幾號。
- **編號**：資料夾裡最大的號、用過的最大號（設定檔記的）比較大的 +1，清掉了、換資料夾也不重用；只認資料夾最上層、純數字的 `.png`。
- **存在截圖資料夾**：不在紀錄資料夾裡、備份不包；位置記在設定檔（`settings.json` 的 `shotDir`，用過的最大號是 `shotNo`），預設桌面的 `截圖\`；截圖頁上面寫在哪，「開啟資料夾」用檔案總管打開（沒有先建）、「變更資料夾…」換（原本的不動）。
- **複製**（截完、按「複製」）放進剪貼簿的是**圖＋那個檔**（檔案跟檔案總管 Ctrl+C 一樣）：吃圖的程式貼圖，Claude Code 在 Windows Terminal 按 Ctrl+V 收到的是檔案路徑、自己去讀那個檔；
  Claude Code 按 Alt+V 是讀剪貼簿裡的圖，也可以。
- 底下是**縮圖**：**保留**的在最上面（照名稱），編號的照日期分段（`2026-11-02（一） · 5 張`）、新的在前；點縮圖放大看（Esc、點一下關）。
  保留那段**可以收起來**（點「▸ 保留 · N 張」開關），預設收起來，保留的多了也不會把新截的擠下去；開著還是收著記在這台電腦。
  滑過出現**複製**、**留下來**（名稱那格換成輸入框，Enter 取名搬進 `保留\<名稱>.png`，名稱規則照記事本；Esc 取消）。
- 縮圖、放大看**按右鍵**：**複製**（跟滑過的複製一樣）、**列印…**（跳系統的列印對話框，選印表機、份數；圖縮到一頁裡，小圖不放大）。
- **拖一個框選好幾張**：在截圖頁上按住拖，框到的縮圖都選起來；在選到的上面按右鍵 →「**複製 N 張**」。
  剪貼簿一次只放得下一張圖，好幾張放的是**檔案**（跟檔案總管選好幾個 Ctrl+C 一樣），貼到 Teams、檔案總管這類收檔案的地方。
  只點一下照舊是放大看；點空白處、Esc 取消選取；在沒選到的上面按右鍵就只對那一張。
- **單張不刪**：編號的靠「清掉 N 天前的」整批丟；保留的用「開啟資料夾」在檔案總管刪。
- **清掉 N 天前的**（不常用，放在上面那列最右邊）：天數（預設 30，記在這台電腦）那天（含）以前的編號截圖丟資源回收筒，保留的不動；按了先在同一列問「…（含）以前的編號截圖 N 張丟到資源回收筒？」，「確定清掉」才丟。1 是今天以外全部、0 是全部。
- 外面用檔案總管動了清單跟著變。說明頁「檔案放在哪」也列截圖資料夾

### 常用

常開的程式、檔案、資料夾、網址放這裡。點頁籤列的「常用」（方框伸出箭頭的圖示），左欄換成一張張卡片，中間不換（跟剪貼簿一樣，記事本、文件檢視、截圖開著時也是）。

- **點一下就開**（用 Tab 選到按 Enter 也是）：程式就執行、文件用 Windows 預設的程式開、資料夾用檔案總管打開、網址用瀏覽器開。只開那個路徑，不帶參數。
- **加**：左欄上面三顆——加程式或檔案（`.exe`、捷徑、文件都可以）、加資料夾、加網址（`http://`、`https://` 開頭）；從檔案總管拖檔案、資料夾進來也是加。已經有的不再加。
  名稱預設是檔名（不含副檔名）、資料夾名稱、網址的主機名稱。
- 卡片上：圖示、名稱、底下淡淡寫路徑或網址；找不到的（被搬走、刪掉、隨身碟沒插）整張變淡、寫「找不到」。
- 滑過出現 **✎ 編輯**（改名稱，空的照預設；網址的那筆也能改網址；路徑不能改，要換就加一筆新的）、**× 從常用拿掉**（只從清單拿掉，檔案、資料夾不動，不問）。
- **調順序**：用滑鼠拖到別的位置，或選到那張按 Alt+↑／Alt+↓ 搬一格。
- **右鍵**：開啟、編輯、在檔案總管中顯示、複製路徑（網址是複製網址）、從常用拿掉。
- 清單存在這台電腦的設定檔（`%APPDATA%\daybook\settings.json` 的 `launch`）：程式、資料夾的路徑是這台電腦的，所以不在紀錄資料夾裡，備份不包、換電腦不會帶過去。

### 設定

頁籤列最底下的齒輪「設定」打開小選單，下面每一項都在裡面。

#### 匯入

選資料夾的卡片上、或齒輪「設定」的「匯入…」，選檔案；自動認是哪一種格式（認不出就報錯；兩種以上都像就跳出來問這次用哪一種）。
內建只有 daybook 自己的格式，其他都是擴充：

- **daybook Markdown**（內建）：daybook 自己匯出的 `.md`，匯回來卡片一模一樣
- **擴充的格式**：別人寫的格式放進擴充資料夾，在齒輪「設定」的「格式」按「啟用」才會用；寫法見〈寫格式擴充〉，也可以請 AI 寫（見〈格式〉）。
  自己舊的寫法（例如用記事本記的 txt）也是這樣：在「格式」頁請 AI 寫一個匯入格式，檢查、試跑、安裝

資料夾裡已經有的日子（或待處理）跳出來問一次：「加進去」是一筆一筆比，一模一樣的那筆不再加、其他接在那天最後面；「略過」是那些不匯、其他照匯。
Ctrl+Z 整批復原；原檔只讀，不改

#### 匯出

齒輪「設定」的「匯出…」打開匯出列 → 下拉選單選格式（記在這台電腦）、填起訖日期（預設這週一到今天；‹ › 換到起日那週的上一週／下一週）按「匯出這段」，或按「匯出全部」（最後接待處理）；
匯出列最後的 ✕ 收起來；在回顧畫面按「匯出這段…」也會打開這列，起訖帶回顧的（見〈回顧〉）；跳存檔視窗選位置。格式像匯入一樣可以外掛：

- **daybook Markdown**（`.md`）：每天一個 `##`、每行標題一個 `###`（原文，含 `^編號`）、內容是清單（原文照抄）；
  這份檔就是標準匯出入格式，可以再匯回來
- **Excel**（`.xlsx`）：一筆一列，日期｜星期｜標題｜內容｜狀態｜標記｜事件｜代號；匯出全部時待處理另一張工作表（標題｜內容｜狀態｜隱藏）。
  日期是 Excel 的日期、內容多行放同一格、第一列凍結、可以篩選（不裝套件，自己組的檔）
- **擴充的格式**：已啟用的擴充提供的匯出格式也列在下拉選單裡；寫法見〈寫格式擴充〉，也可以請 AI 寫（見〈格式〉）。
  要別的欄位的 Excel 也是寫擴充：擴充排好工作表、欄、每一格，交給內建的 Excel 組檔

#### 備份

齒輪「設定」→「備份…」，把整個紀錄資料夾（子資料夾、每一個檔都算）壓成一個 zip，壓好跳存檔視窗選放哪
（預設下載資料夾、檔名 `daybook備份_2026-10-29_1430.zip`），存好提示寫存到哪。zip 裡的路徑相對紀錄資料夾，解開就是一個資料夾，
要拿回來用就用左下角「變更資料夾…」選它（沒有「從備份還原」）。設定、擴充、外觀包（`%APPDATA%\daybook`）不在裡面；空的資料夾不會進去

#### 格式

齒輪「設定」→「格式…」打開一頁：

- 內建的匯入格式、匯出格式，裝了幾個擴充、啟用幾個。
- 「**管理擴充…**」另開一張蓋在上面：擴充資料夾（「開啟位置」沒有會先建）、裝了哪些擴充（各提供哪些匯入、匯出格式；已啟用／未啟用／版本不合／壞掉的原因）；
  上面的搜尋框打字就篩（名稱、格式名稱，空白隔開的每個詞都要有），只有清單那塊捲；Esc、✕、點外面只關這張，回到「格式」頁。
  未啟用的按「啟用」先看提醒、再按「確定啟用」；已啟用的可以停用。一個擴充能匯入也能匯出的，啟用一次兩邊都能用。
  不要的按「刪除」→「確定刪除」，整個資料夾丟到資源回收筒（壞掉的也能刪；刪掉啟用中的會一起停用）
- **請 AI 寫一個新的格式**：先選要寫「匯入格式」還是「匯出格式」→「複製 prompt」→「開 Gemini」或「開 ChatGPT」，
  貼上 prompt，接著貼自己檔案的開頭幾十行（匯入）、或寫要的檔案長怎樣（匯出）→
  AI 回的那段程式碼貼回框裡 →「檢查並試跑…」：先檢查（不執行：格式、欄位、語法、不能用的字、選匯入就只能寫匯入格式，匯出也一樣），過了才在獨立程序試跑：
  - 匯入：選要匯入的檔，預覽拆出來的前幾天（別的格式也認得這個檔的話會寫出來，匯入時會問用哪一種）
  - 匯出：拿資料夾裡全部的紀錄匯出，預覽每一種格式是文字幾行（列開頭 30 行）或二進位檔、多大；「存一份看看…」存下來打開看

  →「安裝並啟用」（不匯入也不匯出，之後自己按）。沒通過就按「複製給 AI」貼回給 AI 改：
  複製的是哪一步沒過、每一條問題，AI 看不出原因的（detect 不認得、什麼都沒拆出來）多附檔案開頭 20 行有字的

#### 外觀

齒輪「設定」→「外觀…」打開一頁：

- 最上面一段「**版面**」：「還原預設大小」一次還原拉分隔線調過的大小（沒拉過時變灰）。
- 「**字型**」：「介面字型」「內容字型」下拉選單列出這台電腦裝的字型（第一項是預設：微軟正黑體 UI、Consolas＋微軟正黑體），「內容字的大小」10～24 px（預設 14）；
  內容是卡片、輸入框、文字模式、記事本、剪貼簿裡的字，按鈕、選單的字不跟（整個畫面要大要小用 Ctrl+=，見〈畫面配置〉）。選的字型沒有中文字的話中文用微軟正黑體。
  改了馬上套上、記在這台電腦，底下有一張預覽卡片；「還原預設字型」一次還原（沒改過時變灰）。
- **外觀包**：可以換**背景圖**（淡淡蓋在整個畫面上，點得穿過去）和**空白時的插圖**（「這天還沒有處理過的事」「沒有待處理的事」上面）。
  一組圖是一個外觀包，寫法見〈做外觀包〉；頁上寫裝了幾個、用的是哪一個，
  「**管理外觀包…**」另開一張列出裝了哪些（已啟用／未啟用／版本不合／壞掉的原因），可以搜尋名稱，跟擴充那張一樣；
  按「啟用」就換上、一次一個；黑暗模式用同一張，背景圖自動暗一點。
  不要的在「管理外觀包…」按「刪除」→「確定刪除」，整個資料夾丟到資源回收筒（壞掉的也能刪；刪掉啟用中的會一起停用）
- 不想自己寫 package.json：同一頁的「**用圖檔做一個**」選背景圖、插圖，要的話勾「去掉邊緣連著的底色」（白底、單色底的圖去得乾淨，可以調差多少算底色），
  背景圖調濃淡、位置（鋪滿，或四個角、四邊中間、正中間）、大小（佔畫面寬幾 %）；背景圖可以「＋ 再加一張」，每張各自調，後面加的疊在上面。
  小畫面先看放起來的樣子，按「建立並啟用」。

#### 語言

齒輪「設定」→「語言…」。介面上看得到的字（按鈕、說明、提示、跳出來的錯誤和對話框）都換得了；內建只有繁體中文，其他語言是**語言檔**。

- 「**介面的語言**」下拉選單：繁體中文（內建）和裝了的語言檔，選了馬上換、畫面重新載入（打到一半沒送出的字會不見；記事本沒存的照樣暫存），載入後語言頁開著、提示換成哪個。用哪個記在設定檔的 `lang`。
- **語言檔**清單：使用中／沒有用、這版的字翻了幾條、缺幾條（缺的照中文顯示）、壞掉的寫原因；「**補翻缺的**」（「要翻成」填好那個語言，prompt 只列缺的）、「**刪除**」→「確定刪除」丟到資源回收筒（刪的是用著的就換回繁體中文）。「開啟位置」打開語言檔資料夾（沒有先建）。
- **請 AI 翻一個新的語言**：「要翻成」填語言（例 English）→「複製 prompt」→「開 Gemini」或「開 ChatGPT」貼上 → AI 一段一段回（每段最多 200 條，說「繼續」再回下一段），每段貼進框裡（接著貼）→「檢查」：
  認得幾條、裝了還缺幾條、語言代碼；回錯的（代號對不上、`{…}` 跟原文不一樣）不收、列出來，可以「複製有問題的給 AI」→「安裝並換成這個語言」。
  AI 回的一行一條留不住頭尾的空白：被按鈕、粗體切開的片段要空白的地方，prompt 請 AI 寫 `␣`，檢查時換回空白（英文才不會黏在一起）。
  同名的（不分大小寫）裝過了就補進原本那個檔：原本翻好的留著、這次有的蓋過去，所以一段一段裝、改版後補翻都可以。
- **不翻的**：紀錄檔裡的字（`[待回覆]`、`[標記:分類]`、內建分類「未完」、類型）、資料夾裡固定的檔名（`待辦.md`、`記事本\`、`保留\`…）、匯出檔的內容（Markdown、Excel 的欄名）、給 AI 寫格式的 prompt——翻了舊紀錄就對不上。
  使用者自己打的字（卡片、分類名稱）當然不翻。寫法見〈做語言檔〉

## 檔案放在哪、怎麼移除

右上角「說明」的「檔案放在哪」列出 daybook 在這台電腦放東西的地方（實際路徑，每個後面有「開啟位置」直接用檔案總管打開）和怎麼完全移除：

- **紀錄資料夾**：自己選的那個
- **截圖資料夾**：預設桌面的 `截圖\`（見〈截圖〉）
- **設定與快取**：`%APPDATA%\daybook`（設定檔 `settings.json`（常用的清單也在裡面）、擴充 `extensions\`、外觀包 `skins\`、語言檔 `locales\`、記事本沒存的暫存 `note-backup\` 都在這）。
  安裝版解除安裝時會問要不要一起丟到資源回收筒，預設不刪
- **程式本身**：
  - 可攜版每次開解壓到 `%TEMP%`、正常關掉會刪，當掉留下的下次開 daybook 會自動清
  - 安裝版裝在 `%LOCALAPPDATA%\Programs\daybook`，另外會把安裝程式複製一份到 `%LOCALAPPDATA%\daybook-updater`，跟安裝檔一樣大，解除安裝會一起刪；
    解除安裝後 `%TEMP%\~nsu.tmp\Un_A.exe` 會留著，是所有 NSIS 解除安裝程式共用的暫存複本，可以直接刪

## 從舊版升級

- 改過名字的：「匯入格式」頁 →「格式」、「暫存」→「剪貼簿」、「MD 檢視」→「文件檢視」。
- 剪貼簿原本存在 `暫存.md`：資料夾裡只有它的話，會自動改名成 `剪貼簿.md`。
- 記事本更新到有記事清單的版本後第一次打開，頁籤只開上次在看的那份（和還沒存的），其他從清單點。
- 記事的建立日期：1.60.4 和更早的版本每存一次，建立日期就變成存檔那一刻，所以舊記事的建立日期是那時最後一次存檔的時間。

## 自己做擴充、外觀包、語言檔

### 寫格式擴充

像 VS Code 的擴充：一個擴充一個資料夾，放進擴充資料夾就會列在「設定」→「格式」頁的「管理擴充…」，使用者按「啟用」才會跑。
一個擴充可以提供匯入格式、匯出格式，或兩種都有（同一種格式能匯入也能匯出）。
照著改最快：`examples/extensions/daybook-example-dated/`（一行 `=== 2026-10-27 ===` 隔開每一天，能匯入也能匯出；附 `sample.txt` 可以直接試匯入）。
不想自己寫：同一頁的「請 AI 寫一個新的格式」（先選匯入或匯出），prompt 裡就是下面這些規格。

**放哪**：`%APPDATA%\daybook\extensions\<資料夾>\`（「格式」頁「管理擴充…」的「開啟位置」會打開它，沒有就先建）。
不用重開 daybook：「格式」頁、「管理擴充…」每次打開、每次匯入、每次打開匯出列都會重讀。

**package.json**

```json
{
  "name": "daybook-example-dated",
  "displayName": "範例：日期分隔純文字",
  "version": "1.1.0",
  "main": "index.js",
  "engines": { "daybook": "^1.22.0" },
  "contributes": {
    "importFormats": [
      { "id": "dated-txt", "label": "日期分隔純文字", "hint": "一行 === 2026-10-27 === 隔開每一天", "extensions": ["txt"] }
    ],
    "exportFormats": [
      { "id": "dated-txt", "label": "日期分隔純文字", "hint": "一行 === 2026-10-27 === 隔開每一天，可以再匯回來", "extension": "txt" }
    ]
  }
}
```

| 欄位 | 意思 |
|---|---|
| `name` | 擴充的名稱，不能跟別的擴充重複；啟用記的是它 |
| `displayName` | 畫面上顯示的名稱（可省，省了用 `name`） |
| `version` | `x.y.z`；版本變了使用者要再按一次「啟用」 |
| `main` | 程式檔（可省，省了是 `index.js`） |
| `engines.daybook` | 只能寫 `^X.Y.Z`：daybook 第一碼要一樣、而且不比它舊（daybook 的版本號第一碼是資料格式不相容才跳）。有匯出格式的要寫 `^1.22.0` 以上，`write` 回 `{ sheets }` 的要 `^1.28.0` 以上 |
| `contributes.importFormats` | 提供哪些匯入格式：`id`（程式檔裡的名字）、`label`（格式名稱）、`hint`（一句話說長怎樣，認不出格式時列給使用者看）、`extensions`（選檔視窗用的副檔名） |
| `contributes.exportFormats` | 提供哪些匯出格式：`id`、`label`、`hint`（下拉選單上滑鼠停著會看到）、`extension`（存檔的副檔名，只寫英文、數字，不含 `.`）。`importFormats`、`exportFormats` 至少要有一種 |

**程式檔**：`module.exports = { formats: { <id>: { detect, parse, write } } }`，介面跟內建的格式一樣，都只看傳進來的東西、不碰檔案。
匯入格式要給 `detect`、`parse`：
- `detect(text)` → 是不是這種格式。daybook 會問每一種格式（內建＋已啟用的擴充），只有一種說是就用它；**兩種以上說是，畫面上的匯入會跳出來問使用者這次用哪一種**。
  所以跟內建格式像也沒關係，但不要寬到連別種檔都認，不然每次匯入都要選
  （內建的 daybook Markdown 第一行是 `# `；裝了別的擴充的話，也要跟它們分得出來）。
- `parse(text)` → `{ days: [{ date: 'YYYY-MM-DD', text: 那天的內容 }], todo: 待處理的內容或 null }`，內容照每日檔的寫法（上面〈一天裡面怎麼寫〉）。
  格式不對就丟 `Error`，訊息會顯示給使用者看。

匯出格式要給 `write`：
- `write(data)` → 整個檔案的內容：文字檔回字串（daybook 用 UTF-8 存，要給 Excel 開的 CSV 自己在最前面加 `﻿`）、二進位檔回 `Uint8Array`（照位元組存）。丟 `Error` 訊息會顯示給使用者看。
- 要 Excel 不用自己組 xlsx：`write` 回 `{ sheets: [{ name, columns, rows }] }`，daybook 用內建的 Excel 組檔，`extension` 寫 `xlsx`：
  - `name`：工作表名稱，1～31 個字，不能有 `\ / ? * [ ] :`、頭尾不能是 `'`、不能重複（大小寫不同也算）
  - `columns`：`[[欄名, 欄寬], …]`，欄寬 1～255，欄數不限
  - `rows`：一列一個陣列，照 `columns` 的順序，可以比欄少；一格是文字、數字、`{ date: 'YYYY-MM-DD' }`（存成 Excel 的日期，那欄寬至少 11）、`null` 或 `''`（空的）
  - 樣式照內建：第一列欄名粗體、凍結，整張可以篩選；格子靠上、自動換行；日期顯示 `yyyy-mm-dd`；文字 `=` 開頭也不會變公式
- `data` 是 daybook 組好的（`src/shared/formats/index.js` 的 `exportData`）：
  - `title`、`from`、`to`（第一天、最後一天）、`all`（是不是「匯出全部」）
  - `days`：`[{ date, weekday（日一二三四五六）, text（那天的原文）, entries }]`，舊的在前，沒寫東西的日子不列
  - `todo`：`{ text, entries }`，匯出全部才有，不然 `null`
  - `entries` 每一筆：`heads`（標題行原文）、`title`（不含行尾標記和 `^編號`，好幾行標題用換行接）、`body`（內容一行一行，第一層縮排拿掉，更深的還是 Tab 開頭）、
    `status`、`hidden`、`flagged`、`flagCat`、`event`、`codes`、`types`、`people`、`tickets`、`topics`（後五個是從標題自動抓的，見〈工具自動抓的東西〉）

daybook 會再檢查：匯入的日期是真的日期、沒有重複、內容是文字，換行改成 `\n`；匯出回的是字串、`Uint8Array` 或合規矩的 `{ sheets }`。不對、丟錯、跑超過 10 秒，都整批不寫，提示寫是哪個擴充。
擴充的程式只在使用者按「匯入…」或匯出時，在另一個程序裡跑（`utilityProcess`）；它還是有使用者帳號的全部權限，**只裝信得過的**。

### 做外觀包

一個外觀包一個資料夾，只有圖和 `package.json`、沒有程式。放進 `%APPDATA%\daybook\skins\<資料夾>\`（「設定」→「外觀」頁「管理外觀包…」的「開啟位置」會打開它，沒有就先建），
打開「外觀」頁的「管理外觀包…」就會列出來。
「外觀」頁的「用圖檔做一個」做出來的也是這樣一個資料夾（名稱就是資料夾名稱，圖存成 `background.*`、`background-2.*`…、`empty.*`），可以照下面再改。

```json
{
  "name": "my-skin",
  "displayName": "我的外觀",
  "version": "1.0.0",
  "engines": { "daybook": "^1.14.0" },
  "contributes": {
    "skin": {
      "background": { "image": "background.jpg", "opacity": 0.12, "position": "cover" },
      "empty": { "image": "empty.png" }
    }
  }
}
```

| 欄位 | 意思 |
|---|---|
| `name`、`displayName`、`version`、`engines.daybook` | 跟〈寫格式擴充〉一樣 |
| `contributes.skin.background` | 背景圖：`image` 圖檔、`opacity` 多濃（0～1，可省，省了是 0.12）、`position` 放哪（可省，省了是 `cover`：整張鋪滿、置中；或 `top-left`、`top`、`top-right`、`left`、`center`、`right`、`bottom-left`、`bottom`、`bottom-right`）、`size` 不鋪滿時佔畫面寬幾 %（1～100，可省，省了是 30）。好幾張就寫成陣列 `[ {…}, {…} ]`，每張各寫各的，後面的疊在上面 |
| `contributes.skin.empty` | 空白時的插圖：`image` 圖檔。最高 120px |

`background`、`empty` 至少要有一種。圖檔寫相對路徑、要在外觀包的資料夾裡；png、jpg、gif、webp、svg。
「外觀」頁上沒有手寫的說明（有「用圖檔做一個」就用不到）；要手寫或改做好的，照這裡。

### 做語言檔

一個語言一個 JSON 檔，只有字、沒有程式。放進 `%APPDATA%\daybook\locales\<名稱>.json`（「語言」頁的「開啟位置」會打開它，沒有就先建），
再打開「語言」頁就能選。「請 AI 翻」裝的也是這樣一個檔，可以直接給別人。

```json
{
  "daybookLocale": 1,
  "name": "English",
  "lang": "en",
  "strings": {
    "格式…": "Formats…",
    "已隱藏 {n} 筆": "{n} hidden"
  }
}
```

| 欄位 | 意思 |
|---|---|
| `daybookLocale` | 固定寫 `1` |
| `name` | 語言的名稱，選單上顯示；「請 AI 翻」同名的（不分大小寫）會補進這個檔 |
| `lang` | 語言代碼（BCP 47，例 `en`、`ja`、`zh-CN`），畫面的 `<html lang>` 換成它；可省 |
| `strings` | 原文對翻譯。原文就是畫面上的繁體中文（程式裡的 `L('原文')`、HTML 的固定文字，空白縮成一個），這版全部的列在 `src/shared/i18n-keys.json`。`{n}` 這種大括號要照留（位置可以換）；沒有的、空的照中文顯示 |

不比版本：daybook 改版加了字、改了原文，那幾條就是「缺的」，照中文顯示，在「語言」頁按「補翻缺的」補。
