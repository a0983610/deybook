# daybook · 工作流水帳

> 狀態：**第一版的功能都有了**（已處理／待處理、卡片輸入、搜尋、代號／事件時間軸）；
> 主題頁、輸出單一文件、快捷鍵還沒做。

取代 `每日工作紀錄2026.txt` 那本記事本：照原本的寫法一天一天記，
工具負責把同一支程式、同一個主題的紀錄串起來——「記」跟記事本一樣快，「找」比記事本快。

## 文件分工

| 檔案 | 裝什麼 | 什麼時候改 |
|---|---|---|
| `README.md`（這份） | 產品說明：資料格式、功能、檔案、怎麼跑 | 格式／功能／檔案／指令變了才改 |
| `CLAUDE.md` | 開發規矩與流程 | 規矩變了才改 |
| `開發筆記.md` ＋ `開發筆記/` | **每個決定的來龍去脈**，依主題分檔，每條有編號（`D001`…），`開發筆記.md` 是索引 | 每做完一個決定就補 |
| `e2e測試.md` | 測試怎麼分層、有哪些案例、怎麼跑 | 加功能就加案例 |

**接手開發前先讀 `CLAUDE.md`。**

## 資料格式

### 每天一個檔

```
<資料資料夾>/                          ← 不在專案裡，位置在程式裡設定（D016）
├── 待辦.md                           ← 待處理：還沒處理完的事，不分哪一天（D019、D024）
├── journal/2026/10/2026-10-05.md    ← 已處理：一天一檔，檔名就是日期
└── topics/多統編發票.md               ← 跨好幾支程式的主題頁（需要才建）
```

為什麼不是一件事一個檔：見 開發筆記 D004。

### 一天裡面怎麼寫（跟舊 txt 一樣）

```
CWIN301000 撥入單 BUG
	Q1.備料單產生的單據，走自動核准按修改、刪除時請直接擋住
	Q2.查詢\來源單別，請將「請選擇」改為「全部」 (撥出單一起調)
雅琦問題：發票號碼XA34259000已於1/21作廢，但1/22又產生一次作廢的XML [待回覆]
	->雅琪問台應看看
```

| 寫法 | 意思 |
|---|---|
| 沒縮排的行 | **條目標題** |
| Tab（或空白）縮排的行 | 條目內容 |
| `->` 開頭 | 處理結果／原因，畫面上特別標示 |
| 標題行**最後面**的 `[待回覆]` | 狀態，現在只在待處理用（沒標就是待處理）。只認標題行尾；舊的 `[待處理]` `[完成]` 也認得（見 D006、D024） |
| 標題裡的 `^數字`（放在狀態前面） | 事件編號：已處理的事隔天又有後續時，今天另記一筆、用同一個編號串起來；按「+ 更新」時自動編（見 D022） |
| 待處理裡的 `->MM/DD …` | 待處理那一筆的進展，按「+ 更新」時自動帶日期（見 D024） |
| 標題行尾的 `[隱藏]` | 待處理先收起來不看，可以跟 `[待回覆]` 同時有：`週報 [隱藏] [待回覆]`（見 D026） |
| 標題裡的 `#主題名` | 把這筆歸進 `topics/主題名.md` |
| 連續幾行只有「代號＋程式名稱」的標題，底下才接內容 | 這幾支程式共用那段內容（規則見 D009） |

### 工具自動抓的東西

不用另外標，從標題行抓（見 D007）：

| 抓什麼 | 例 | 用途 |
|---|---|---|
| 程式代號 | `CWMM3030`、`eWCH3050`、`TX_GetInvoiceNumber`（標題裡任何位置都算） | 同代號的條目自動串成時間軸 |
| 類型 | `BUG`、`BB`、`規格調整`、`新程式` | 篩選 |
| 人名 | `秀屏問題`、`看雅琦問題` → 秀屏、雅琦 | 篩「誰來問的」 |
| 工單號 | `Wc3620251231005` | 篩選 |

### 主題頁

```markdown
---
title: 支援開立多統編發票
status: 完成
---
摘要、規格重點、相關單號……
```

主題頁只放摘要；歷程不用抄，工具把所有標了 `#多統編發票` 的條目接在下面。

## 功能

### 第一版

1. **匯入舊檔**：把 `每日工作紀錄2026.txt` 拆成每日檔，檔尾「週報」那段搬進 `待辦.md`（原檔只讀，不改）
2. **已處理／待處理**（D024）：中間上面是這一天已處理的事，下面是待處理（不分哪一天，一直都在）。
   兩塊的高度跟著內容走、剩下的給輸入區（D029）；點標題列可以縮起來（D027）
   **刪除不跳詢問；按錯了按 Ctrl+Z 復原上一個卡片動作**（游標不在輸入框時，D028）
3. **卡片輸入**（D021、D025）：一打開停在今天。最底下的表單填標題（Enter 換到內文）、內文，
   按 **＋ 待處理**（Ctrl+Enter）或 **＋ 已處理（這一天）**（Ctrl+Shift+Enter）
4. **待處理的卡片**：**待回覆**（點一下切換）、**+ 更新**（接在底下、帶今天日期）、**處理完 ↑**（整筆搬到上面正在看的那一天）、
   **隱藏**（收到最底下「已隱藏 N 筆」，點一下展開、可以取消隱藏）、編輯、刪除
5. **已處理的卡片**：**+ 更新**、編輯、刪除
   - 今天的：在同一筆底下加一行 `->…`
   - 過去的：在今天另記一筆，用 `^編號` 跟原本那筆串起來（D022）
6. **文字模式**：右上角切換，上下兩塊都變成原文直接打字、自動存檔（D020）
7. **日期清單**：左邊列日期，點了看那天
8. **搜尋**（D023）：左上搜尋框（Ctrl+F），空白隔開的每個詞都要出現，標題和內容都算
9. **時間軸**：點卡片上的代號標籤，列出那支程式所有紀錄；點 `^編號` 標籤，列出那件事每一天的紀錄。舊的在前

### 之後

- 主題頁與 `#主題` 彙整
- 人名、類型篩選
- 輸出單一文件：依日期區間（還原成舊 txt 那樣的流水帳）、依代號或主題（某件事從頭到尾）（見 D010）
- 全域快捷鍵叫出視窗快速記一筆、系統匣常駐

## 檔案

```
daybook/
├── README.md、CLAUDE.md、開發筆記.md、e2e測試.md
├── 開發筆記/*.md             依主題分檔
├── package.json
├── src/
│   ├── main/main.js         Electron 主程序：資料夾、讀寫檔案、監看資料夾、IPC
│   ├── preload.js           只開放必要的讀寫 API 給畫面
│   ├── shared/parser.js     解析條目：代號、類型、人名、狀態、事件編號、工單號；卡片 → 行
│   ├── shared/entries.js    卡片的加／改／刪／搬、狀態、事件編號、更新（純文字操作）
│   ├── shared/search.js     搜尋、時間軸
│   ├── shared/paths.js      每日檔路徑、待辦.md
│   └── renderer/            畫面（index.html / app.js / style.css）
├── scripts/import-txt.js    一次性：舊 txt → 每日檔＋待辦.md
└── tests/                   見 e2e測試.md
```

紀錄資料不在這裡：位置在程式裡設定，見 D016。

## 怎麼跑

```
npm install                     裝 Electron 45.0.0；執行檔第一次啟動時才下載
npm start                       啟動；第一次會跳視窗選資料資料夾（存在 %APPDATA%\daybook\settings.json）
npm start -- --data-dir <資料夾>  指定資料資料夾，不讀寫設定（開發、測試用，見 D016）
node tests/parser.test.cjs      解析層＋匯入層測試
node tests/e2e.cjs              e2e 測試（會短暫開出視窗，見 e2e測試.md）
node scripts/import-txt.js <舊檔.txt> --out <資料資料夾> --todo-from 週報
                                舊 txt 拆成每日檔，「週報」那行起搬進 待辦.md；
                                目標檔已存在就整批不寫（見 D018、D019）
```
