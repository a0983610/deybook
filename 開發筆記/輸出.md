# 輸出

這個主題的決定。索引與寫法見 `開發筆記.md`。

## D010 輸出單一文件有兩種切法

- **日期**：2026-10-22
- **狀態**：已定案（要做）；格式定了、日期區間做了（見〈後續〉）；依代號或主題還沒做
- **相關**：D007、D035

> 使用者：「也能靠這工具轉換單一文件 或做出事件的關聯」

**決定**：第二版做，兩種切法——
- 依日期區間：還原成舊 txt 那樣的流水帳（寫週報、月報用）。
- 依代號或主題：某件事從頭到尾的歷程（交接、檢討用）。

**後續**：
- 2026-10-22：使用者選了格式 **Markdown**（不是舊 txt 寫法）、範圍「日期區間」＋「全部」；「目前看到的結果」（依代號、搜尋）這次沒選 → 見 D035。

## D035 匯出成一份 Markdown：起訖日期或全部，存檔視窗選位置

- **日期**：2026-10-22
- **狀態**：已定案（範圍、格式、選日期的方式是使用者選的）；Markdown 的細節寫法是 Claude 提的
- **相關**：D009、D010、D016、D025

> 使用者：「增加黑暗模式 可以參考vscode 匯出成單一檔案功能」
>
> 使用者（Claude 問範圍／格式／選日期，選項附範例）：範圍選「日期區間」「全部」（沒選「目前看到的結果」）；
> 格式選「Markdown」（另兩個是「txt，跟舊記事本一樣」「HTML」）；選日期選「只要起訖兩格日期」（另兩個是「快速鈕＋自訂」「在左邊日期清單選」）

**決定**：
- 標題列「**匯出…**」打開一列：起、訖兩格日期（含頭尾，預設這週一到今天）、「**匯出這段**」「**匯出全部**」。再按一次「匯出…」收起來。
- 按了跳 Windows 存檔視窗選位置（預設下載資料夾、檔名 `工作紀錄_起_訖.md`／`工作紀錄_全部_今天.md`；同一次開著會記住上次存的資料夾）。
- 「全部」從第一天到最後一天，最後接 `## 待處理`（含隱藏的，標 `[隱藏]`）。
- 寫法（`src/shared/export.js`）：
  - `# 工作紀錄 起 ～ 訖`；每天 `## 2026-01-21（三）`；每筆 `### 標題`，內容一行一項 `- …`。沒寫東西的日子不列。
  - 好幾行標題共用內容的（D009）用「 / 」接成一行；狀態照寫 `[待回覆]`；事件編號 `^N` 不寫（是工具內部串東西用的）。
  - 內容多的縮排變下一層清單；開頭的 `->` 變 `→ `。
  - 開頭會被 Markdown 當語法的（`1. `、`- `、`# `、`> `）前面加 `\`，照原字顯示；`1.控管` 這種點後面沒空白的本來就不算，不動。
- 起日晚於訖日、那段沒有紀錄：跳提示、不寫檔。

**為什麼**：
- 預設「這週一到今天」：「週報」一直放在待處理，寫週報最常用。
- 舊檔裡內容以 `1. ` 開頭的有好幾段（12/30 那筆就 4 行），不跳脫的話 Markdown 會重新編號、跟原文不一樣。
- 真資料（舊檔 189 天）匯出全部：3350 行、117KB、約 5ms；日期數、每筆標題數、每行內容數都跟原檔一樣（R4）。

**沒採用的做法**：
- txt（舊記事本寫法）、HTML：使用者選 Markdown。
- 快速鈕（這週、上週……）、在日期清單選範圍：使用者選只要兩格日期。
- 存檔視窗之外，另外記住上次的資料夾到設定檔：只在這次開著時記；--data-dir 時不讀寫設定檔（D016）。

**影響**：
- `src/shared/export.js`（純函式）；`main.js` 的 `exportMd`、`export`；`preload.js` 的 `exportMd`；`app.js` 的匯出列；`index.html` 的 `#exportBar`。
- **`--export-dir <資料夾>`**：只給測試用，匯出不跳存檔視窗、直接寫進那個資料夾（原生存檔視窗 CDP 點不到）。
- 測試 X1、R4、E31。

**實測**（2026-10-22）：parser 152 條、e2e 111 條全過；拿舊檔匯出全部看過長相（`1\. ` 跳脫、多層清單、待處理在最後）。

**後續**：
- 2026-10-27：匯出改成能匯回來（每行標題一個 `###`、`^編號` 照寫、內容原文照抄，不改 `->`、不跳脫），`export.js` 搬到 `formats/daybook-md.js` → 見 D046。

## D046 匯出的 Markdown 就是標準匯出入格式：匯出再匯回，卡片一模一樣

- **日期**：2026-10-27
- **狀態**：已定案（用現在的 MD 當標準格式、標題寫出 `^N`、細節交給 Claude 定，是使用者說的）；細節寫法是 Claude 定的
- **相關**：D008、D009、D022、D035、D044、D047

> 使用者：「匯入匯出 要相同格式 能把匯出檔案再次匯入」
>
> 使用者：「標準匯出入 格式就用現在的MD」
>
> 使用者（Claude 問匯出標題多出 `^N` 可不可以）：「匯出的標題多出 ^N 可以(匯出入標準格式你決定就好 沒打算給人看)」

**決定**：
- 匯出（`formats/daybook-md.js` 的 `toMarkdown`）：
  - 每一行標題各寫一個 `### 原文`，`^編號`、`[隱藏]`、`[狀態]` 都照原文寫。共用內容的好幾行標題（D009）連著寫、中間不空行；不同筆之間空一行。
  - 內容：第一層縮排拿掉，後面多的 Tab 變下一層清單，其他字原樣照抄（`->` 不改成 `→`、開頭不加 `\` 跳脫）。
  - `# 標題`、`## 2026-01-21（三）`、`## 待處理`、`（沒有）` 照舊。
- 匯入（同一個檔的 `parse`）是反方向：`### ` 後面整行是標題原文、`- ` 後面整行是內容原文（前面補一個 Tab，清單每深一層多一個 Tab）；筆跟筆之間補一個空行。
  認不得的行、第一個日期之前就有內容、同一天兩次、不存在的日期、`## 待處理` 兩次、標題會被當成內容（空白或「數字＋.」開頭）、清單沒有字：報錯寫第幾行，不猜（同 D018）。星期不看。
- **保證**：匯出再匯回，卡片一模一樣（標題原文、內容、狀態、隱藏、`^編號`、哪幾行共用內容）。
  會變的只有不影響卡片的：第一層的空白縮排變 Tab（D008）、內容中間的空行拿掉、沒縮排的「1.」內容（D008）前面多一個 Tab。

**為什麼**：
- 原本的匯出匯不回去：`^N` 不寫；共用內容的標題用「 / 」接成一行，標題本身有「 / 」就分不出來；`->` 一律變 `→ `，舊檔 L596 `-> 施工中` 的空白會掉；內容開頭的 `\` 分不出是原文還是跳脫加的。
- 用「每行標題一個 `###`＋空行分筆」，不用「 / 」：parser 分共用內容是看光頭標題有沒有連著，空行會打斷（D009，`parser.js` 的 `parseDay`）。
  只要匯回的標題行順序、連不連著跟原本一樣，D009 算出來就一樣，不用另外記哪幾行共用，標題裡有「 / 」也不怕。
- 不改 `->`、不跳脫：檔案不是給人看的（使用者說的），原文照抄最不會出錯。舊檔裡原文就以 `→`、`\` 開頭的內容 0 行（grep 量的），但新寫的可能有，跳脫規則一多就有還原不回來的邊角。
- 實測（2026-10-27）：舊檔（只讀）189 天、642 張卡、待處理，匯出再匯回全部一樣（parser R6）；邊角寫法 X2；從畫面匯進空資料夾 E39。

**沒採用的做法**：
- 每天的原文整段照抄進 MD（位元組都一樣）：標題行可能剛好以 `## ` 開頭，跟日期標題分不出來，還是要跳脫；使用者要用現在的 MD。
- 保留「 / 」接標題、再加跳脫：多一套規則，換來的只是 Markdown 預覽好看，檔案又不給人看。
- `^N` 藏在 `<!-- ^3 -->`：使用者說可以直接寫。

**影響**：
- `src/shared/export.js` 搬到 `src/shared/formats/daybook-md.js`：匯出、匯入寫在同一個檔，改一邊要看另一邊。`main.js`、測試的 require 跟著改。
- 1.4.0 以前匯出的檔也匯得進來，但 `^N` 本來就沒寫，共用內容的標題會變成一行「A / B」，`->` 會是 `→ `。
- 匯進來的 `^N` 照原號碼寫：拿自己的匯出還原沒問題；匯進另一個資料夾、那裡剛好用了同樣的號碼，兩件不相干的事會被串在一起。先不處理（2026-10-27 跟使用者說過）。
- 測試 X1（改）、X2、X3、M1（加匯出檔）、R4（改）、R6、E39。
