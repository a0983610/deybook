這個主題的決定。索引與寫法見 `開發筆記.md`。

## D047 匯入格式做成模組：一種格式一個檔、自動認；之後開放外部擴充

- **日期**：2026-10-27
- **狀態**：已定案（做成外掛式的格式、這次只做第一階段、第二階段之後要做，是使用者說的）；介面、自動認格式的規則是 Claude 提的
- **相關**：D018、D040、D044、D046

> 使用者：「目前我的格式匯入 設計成一個可以外掛的方式去支援匯入各種文字格式」
>
> 使用者：「外掛模組是想像vscode能夠去支援各種格式(評估)」「我的舊筆記 就是非標準格式 要另外支援匯入」
>
> 使用者（Claude 評估兩階段後）：「外掛先只做第一階段 然後也是要做第二階段(希望以後不只我一個人用)」

**決定（第一階段，這次做的）**：
- `src/shared/formats/` 一種格式一個檔，`formats/index.js` 登記。現在兩種：
  `daybook-md.js`（標準格式，D046）、`notepad-txt.js`（舊記事本，原本 `import.js` 的拆法搬過來，規則照 D008、D018、D019）。
- 每個格式模組給：`label`（名稱）、`hint`（一句話說長怎樣）、`extensions`（選檔視窗用）、`detect(text)`、`parse(text) → { days: [{ date, text }], todo }`。純函式、不碰檔案。
- 寫檔、已經有的日子跳過（D044）、Ctrl+Z 整批復原都在主程序／`import.js`，每種格式都一樣，格式模組管不到。
- 匯入時自動認：只有一種 `detect` 認得才用它；都不認得（錯誤訊息列出能匯入的格式）、兩種以上都認得就報錯，不猜（同 D018）。匯完的提示寫認成哪一種。
- 認法：舊記事本是「有日期行 `1/5`、`---年份---`、或『週報』那一行」；daybook Markdown 是「第一行有字的是 `# `，而且有 `## 日期` 或 `## 待處理`」。
  兩種不會同時成立：匯出檔每一行都是 `#`、`- `、空白縮排的 `- ` 或 `（沒有）` 開頭，不會有只寫日期的行。
- 選檔視窗的副檔名照登記的格式；兩顆匯入鈕（左下角、選資料夾卡片）都能匯所有格式，卡片上的字從「從舊記事本匯入…」改成「匯入…」。

**第二階段（之後做，像 VS Code 的擴充）**：
- 擴充放 `%APPDATA%\daybook\extensions\<名稱>\`：裡面的 `package.json` 宣告名稱、版本、相容的 daybook 版本、提供哪些格式，加上程式檔；丟進去、重開 daybook 就有，不用重新打包。
- 介面跟第一階段一樣（`label`、`hint`、`extensions`、`detect`、`parse`），內建的兩種格式不用改。
- 要另外做：讀 `package.json`、檢查版本相容；擴充放獨立程序跑（壞掉、跑太久不會拖垮 daybook）；檢查回傳的資料（日期格式、有沒有重複、是不是字串）；畫面列出裝了哪些擴充；測試。
- 風險：擴充的程式碼有使用者帳號的全部權限（VS Code 的擴充也沒有沙箱），只能裝信得過的；給別人用之前要想好怎麼提醒。

**為什麼這次只做第一階段**：目前只有兩種格式、使用者一個人用。第一階段先把介面定好，第二階段只是多一個「從哪裡載入」，格式本身不用動。

**沒採用的做法**：
- 設定檔描述規則（用 JSON 寫日期行長怎樣、哪行是標題）：舊記事本的年份標記、D009 這種規則寫不進去。
- 先在畫面上選格式再選檔：多一步；格式之間認得出來就不用問。
- `detect` 多傳檔名：現在兩種格式都只看內容；之後擴充需要再加（多傳一個參數不影響舊的）。

**影響**：
- 新增 `src/shared/formats/index.js`、`notepad-txt.js`；`import.js` 只剩 `planImport`（認格式、拆、跳過已有的）；`scripts/import-txt.js` 改用 `notepad-txt.js`。
- `main.js`：`pickTxt` → `pickImportFile`、`importTxt` → `importFile`、IPC `import:txt` → `import:file`；`preload.js` 的 `importFile`；`app.js` 的提示多寫格式名；`index.html` 兩顆鈕的說明。
- **加一種格式**：在 `formats/` 加一個檔、`index.js` 登記一行，parser 測試補 F1 和匯入案例；跟現有格式要認得出差別（不然會「兩種都像」）。
- 測試 F1、M1、E37（提示寫格式）、E38、E39。
